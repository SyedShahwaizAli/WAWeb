# WA Web (Android 5.0+ ke liye)

WhatsApp Web ko WebView mein load karne wali simple app. Android 5.1.1 pe chalti hai.

## APK banane ke 2 tareeqe
1. **Android Studio**: Open project folder -> Build > Build APK(s) -> app/build/outputs/apk/debug/app-debug.apk
2. **GitHub Actions (PC ke baghair)**: Is folder ko GitHub repo mein upload karo -> Actions tab -> "Build APK" -> artifact download karo.

## Use
Phone mein APK install karo (Unknown sources allow) -> app kholo -> dusre phone se WhatsApp > Linked Devices > Link a device -> QR scan karo.
